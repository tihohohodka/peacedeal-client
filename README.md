# PeaceDeal Client

PeaceDeal - это веб-приложение для создания и отслеживания обещаний между людьми. 

Этот репозиторий содержит клиентскую часть приложения, построенную с использованием React. Проект запущен на связи Vercel + Render. 
https://peacedeal-client.vercel.app/

**В связи с тем, что проект запущен на бесплатных тарифах, то подключение к базе данных может занимать некоторые время, для получения более точного представяления о проекте перезагрузите страницу через минуту после перехода по ссылке.**

## 🚀 Особенности

- 📝 CRUD-система для управления обещаниями
- 📅 Отслеживание сроков выполнения
- 👥 Система безопасной авторизации пользователей
- 🎨 Адаптивный интерфейс
- 🔍 Поиск обещаний по тегам и ключевым словам (в процессе реализации)

## 🛠️ Технологии

- React
- React Router для навигации
- Axios для HTTP-запросов
- Vite для сборки проекта
- CSS для стилизации
- REST API для связи с сервером

## 🏃‍♂️ Запуск проекта

1. Клонируйте репозиторий:
```bash
git clone https://github.com/tihohohodka/peacedeal-client.git
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm run dev
```
